# Переход Sparkle на сервер компании

Версия 0.1.40 (сборка 44) — переходный выпуск. Для неё в `Config/provisioning.local.json` поле `updates.baseURL` установлено в `https://update.elitesip.vip:8081`. Файл с паролями не хранится в Git; перед каждой следующей сборкой нужно проверить этот адрес в локальном конфиге и в собранном `EliteSIP.app/Contents/Resources/provisioning.json`.

Выпуск 0.1.40 публикуется в прежний канал `https://get.elitesip.vip`: уже установленные версии проверяют именно его. После установки 0.1.40 приложение проверяет `appcast-arm64.xml` или `appcast-x86_64.xml` на новом сервере. Следующий выпуск нужно публиковать на новом сервере через `elitesip-publish` из репозитория `elitesip_update`.

Новый канал использует HTTPS на порту 8081 и ту же Basic-пару в настройках клиента и серверных переменных. Перед публикацией переходного выпуска на старом канале оба appcast нового канала и соответствующие ZIP должны открываться с этой парой. Сборку с нижними планками macOS 10.15 для Intel и 11.0 для Apple Silicon выполнять установленным Xcode 26.6 через `DEVELOPER_DIR=/Applications/Xcode-26.6.app/Contents/Developer`; Xcode 27 не поддерживает эту цель развертывания.
